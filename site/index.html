# Send an ad hoc request
$ kestrl send GET '{{api_url}}/health' -e local
{
  "id": "01J8Q6M2W7R4",

  "body": { "ok": true },
  "redacted": ["local_token"],

# Find the event in shared history
$ kestrl history --since 1h
        200  GET  /health  84ms  actor: me

The token used by this request was masked in output and stored history.

One workspace, six tools.

Kestrl keeps the everyday backend loop close at hand. Project files stay in your repository; history and live buffers stay on your Mac.

Requests & environments

Save TOML request files, resolve variables and profiles, and send against named environments.

History with actors

Search, replay, compare and tag requests. Events show whether you, Codex, Claude Code or Cursor ran them.

Service logs

Start a process through Kestrl or attach to a log file or Docker container. Tail and filter the live buffer.

Database console

Query PostgreSQL and inspect tables. Connections are workspace files; writes are disabled unless an environment allows them.

Traffic capture

Capture simulator, emulator and browser traffic, or plain HTTP on a local port.

macOS app

Edit requests, inspect history, read logs, query databases and capture traffic in a native SwiftUI app.

Made for the agent loop.

Agents call kestrl instead of curl. Each request lands in the same history as app activity, with an actor attached and secrets masked before they reach output.

Call. Record. Return.

A send is both a request and a durable event. Find it later by time, actor, session or tag; replay saved requests with secrets resolved again from the Keychain.

$ kestrl history --by codex --since 1h
$ kestrl history replay 01J8Q6M2W7R4

Private by default.

Kestrl has no accounts, cloud sync or telemetry. Workspace configuration and request files can live in git. Credentials stay in the macOS Keychain and are injected only when a request runs.

Start from source.

Kestrl is open source and built for macOS. Install the CLI with Cargo, or build the native app from the repository.

Quick start and workspace setup →

git clone https://github.com/AdityaAmitK/kestrl
cd kestrl
cargo install --path crates/kestrl-cli

Build the app with scripts/build-app.sh.
