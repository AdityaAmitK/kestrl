Workspace concepts

Kestrl keeps editable project inputs in the repository, credentials in a private secrets file, and request history in a local database.

Workspace files

Workspace configuration lives in .kestrl/. Request files usually live in a repository-level requests/ folder.

.kestrl/
  kestrl.toml                 # default environment and retention
  envs/local.toml             # [vars] for local work
  envs/prod.toml
  profiles/admin.toml
  connections/main.toml
requests/auth/login.req.toml

Environment

[vars]
api_url = "http://localhost:3000"
token = "{{secret:local_token}}"

Request file

name = "Login"
method = "POST"
url = "{{api_url}}/auth/login"
profiles = ["admin"]

[headers]
Authorization = "Bearer {{token}}"

[body]
type = "json"
content = '''{ "email": "person@example.test" }'''

Profile conditions

Profiles add headers or query parameters. A [when] block applies the profile automatically only when every condition matches.

[headers]
X-Admin-Token = "{{secret:admin_token}}"

[query]
debug = "1"

[when]
env = ["local", "staging"]
url = "*/dev/*"

Connection

kind = "postgres"
allow_writes = ["local"]

[env.local]
url = "postgres://{{secret:db_local_user}}:{{secret:db_local_pass}}@localhost:5432/app"

Resolution order

Variables resolve in this order: --var k=v, then collection folder variables from folder.toml (nearest folder first, environment-specific before general), then the environment, then workspace configuration. Without -e, the nearest folder's default_env picks the environment. Request-file headers and query parameters are base values. Profiles apply in this order: request-file profiles, repeated -p profiles, then profiles whose [when] conditions match. Later profile values override earlier ones. Secrets resolve last, at send time.

Retention

DataRetention
Service logsMemory only; rolling buffer of about 10,000 lines per service, cleared when the service stops.
CapturesMemory while capturing; save an exchange to history explicitly.
Requests and queriesPruned to the last 7 days or 500 events, whichever limit is reached first.
Saved eventsKept until deleted.
BodiesCut to 1 MB when stored.

Retention defaults can be configured in .kestrl/kestrl.toml under [retention]: max_age_days, max_events and max_body_bytes.

Local storage

Request history uses SQLite at ~/Library/Application Support/kestrl/history.db in WAL mode so the CLI and app can use it at the same time. Workspace files remain alongside the project. See the capture guide for live-buffer and proxy details.
