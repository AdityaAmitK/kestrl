Documentation

Install the CLI, make a workspace, then send a request. Kestrl keeps project configuration in files and history on your Mac.

Install

Kestrl targets macOS. Pick one method.

Install script

curl -fsSL https://kestrl.adityakinjawadekar.com/install.sh | sh

Homebrew CLI

brew install adityaamitk/tap/kestrl

Homebrew app

brew trust adityaamitk/tap
brew install --cask adityaamitk/tap/kestrl

GitHub Releases

Download the DMG from the latest release and move Kestrl to Applications.

From source

Requires stable Rust and macOS. Install the CLI from a checkout:

git clone https://github.com/AdityaAmitK/kestrl
cd kestrl
cargo install --path crates/kestrl-cli

Build the macOS app and its Rust framework with scripts/build-app.sh.

The macOS app is not notarized yet. On first launch, open System Settings ▸ Privacy & Security and choose Open Anyway.

Workspace layout

A workspace is a folder, usually your project repository, with a .kestrl/ directory. Requests and workspace configuration are plain TOML and can be reviewed or shared through git.

.kestrl/
  kestrl.toml
  envs/local.toml
  profiles/admin.toml
  connections/main.toml
requests/
  auth/login.req.toml

Your first request

Run kestrl init in your project folder, or choose New workspace… in the app. This creates configuration, a local environment and a health request without overwriting existing files. Start your API on localhost:3000 before sending.

kestrl init
kestrl send requests/health.req.toml

When output is piped, the CLI prints JSON. A sent request is recorded in history, where you can search, inspect or replay it.
