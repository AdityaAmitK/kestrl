Documentation

Install the CLI, make a workspace, then send a request. Kestrl keeps project configuration in files and history on your Mac.

Install from source

Kestrl currently targets macOS and requires stable Rust for the CLI build.

git clone https://github.com/AdityaAmitK/kestrl
cd kestrl
cargo install --path crates/kestrl-cli

Build the macOS app and its Rust framework from a checkout with:

scripts/build-app.sh

Workspace layout

A workspace is a repository with a .kestrl/ directory. Requests and workspace configuration are plain TOML and can be reviewed or shared through git.

.kestrl/
  kestrl.toml
  envs/local.toml
  profiles/admin.toml
  connections/main.toml
requests/
  auth/login.req.toml

Your first request

Store a credential in the macOS Keychain, then send a request file against the local environment. The value is resolved when the request runs.

kestrl secret set local_token
kestrl send requests/auth/login.req.toml -e local

When output is piped, the CLI prints JSON. A sent request is recorded in history, where you can search, inspect or replay it.
