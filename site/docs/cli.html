CLI reference

The commands and options below reflect kestrl --help and the nested command help. Global options can be placed before the command; repeatable options accept multiple values.

Global options

OptionWhat it does
--actor <ACTOR>Set the actor recorded for this command. Recognized examples include me, cursor, claude-code and codex.
--jsonForce JSON output. JSON is the default when stdout is not a terminal.
-h, --helpPrint help.
-V, --versionPrint version.

Requests and workspace

init — create a workspace

Creates .kestrl/kestrl.toml, .kestrl/envs/local.toml and requests/health.req.toml. DIR defaults to the current directory and is created if missing. Existing workspaces or starter files are rejected without overwriting. JSON output includes created paths and next steps.

kestrl init [DIR]
kestrl init my-project --json

send — send one request

Accepts a request file path, or an HTTP method followed by a URL.

kestrl send [OPTIONS] <TARGET>...

-e, --env <ENV>           Environment name
-p, --profile <PROFILES>  Profile name; repeatable
    --var <VARS>          Variable override, key=value; repeatable
    --tag <TAG>           Tag to add to the recorded event
    --actor <ACTOR>       Actor recorded for the command
    --json                Force JSON output
kestrl send requests/auth/login.req.toml -e local
kestrl send GET '{{api_url}}/users' -e local --tag auth-check

run — send a collection

kestrl run [OPTIONS] <DIR>

-e, --env <ENV>
-p, --profile <PROFILES>  Repeatable
    --var <VARS>          key=value; repeatable
    --actor <ACTOR>
    --json

envs and profiles

List entries with no name, or show one entry by name. Resolved environment output masks secrets.

kestrl envs [NAME]
kestrl envs local
kestrl profiles [NAME]
kestrl profiles admin

secret — manage Keychain values

Subcommands: set, rm and ls. Set reads the value from stdin or a prompt; ls lists secrets referenced by the workspace.

kestrl secret set local_token
kestrl secret rm local_token
kestrl secret ls

History and sessions

history — search events

kestrl history [OPTIONS] [QUERY]

--by <ACTOR>       Filter by actor
--tag <TAG>        Filter by tag
--since <SINCE>    30s, 2m, 1h or 2d
--session <SESSION> Filter by session
--limit <LIMIT>    Maximum events (default 20)
--json

History subcommands are show (show an event), edit (change actor or note), replay (send a past request again), and diff (compare two HTTP events).

kestrl history show <id>
kestrl history edit <id> --set-actor codex
kestrl history replay <id>
kestrl history diff <a> <b>

tag accepts an event ID or unique prefix and a tag; add --remove to remove it. session starts or ends a session.

kestrl tag <event> login-bug
kestrl tag <event> login-bug --remove
kestrl session start [name]
kestrl session end

Services and logs

kestrl up <service> -- <command>...
kestrl ps
kestrl logs [OPTIONS] [SERVICE]

-f, --follow       Follow new lines
--since <SINCE>    30s, 2m, 1h or 2d
--grep <GREP>      Filter with a regular expression
--limit <LIMIT>    Show last n matching lines
--json

kestrl logs attach <service> --file <path>
kestrl logs attach <service> --docker <container>

Use up to start a process through Kestrl. Use logs attach to follow a log file or Docker container for a service Kestrl did not start.

Database

Database commands are query, tables and connections. Use -e to select an environment where documented below.

kestrl db query <connection> "<sql>" [-e <env>]
kestrl db tables <connection> [-e <env>] [<table>]
kestrl db connections

Capture and proxy

kestrl capture sim [--port <port>] [--save] [--host <glob>]
kestrl capture android [--port <port>] [--save] [--host <glob>]
kestrl capture browser [--browser chrome|arc|brave|edge|chromium|helium]
  [--browser-path <path>] [--url <start-url>] [--save] [--host <glob>]
kestrl capture port <port> [--save]
kestrl capture port setup|status|uninstall

kestrl proxy trust --sim|--android
kestrl proxy ca
kestrl proxy restore

Capture host filters accept domains and * patterns. A plain domain includes itself and its subdomains at a dot boundary; patterns match the whole hostname, case-insensitively. Excluded HTTPS hosts tunnel without capture or history entries. See the capture guide for setup and safety behavior.
