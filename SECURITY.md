# Security policy

Kestrl handles API secrets and intercepts network traffic, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through [GitHub security advisories](https://github.com/AdityaAmitK/kestrl/security/advisories/new). Include steps to reproduce and the affected version or commit.

You can expect an initial response within 7 days.

## Scope

In scope: secret leakage (to output, history, logs or disk), certificate and proxy handling, and the system proxy being left enabled.
